## New decisions invented for this project

1. **Arcade payout rule** — ADR-001 (`docs/decisions/`).
2. **Injectable rng / deck-in-action-payload** — keeps the reducer pure without a mocking library; the foundation's factory-seam intent, right-sized.
3. **Framework-free engine enforced by lint, not by folders-only** — the mechanical rule the foundation says prevents its two worst defects.
4. **9/6 paytable** (user-chosen classic Jacks-or-Better) as data, single source in `engine/paytable.ts`.
